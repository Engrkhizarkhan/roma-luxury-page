# SSAROMA Boutique

A single-page brand experience for SSAROMA, an intimate fragrance boutique in Peshawar.

The landing page is intentionally focused on the physical shop, guided scent discovery and a
small editorial fragrance preview. Product browsing is kept separate at
`https://product.ssaroma.com`.

## Development

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
```

Editable shop details and external links live in `src/lib/ssaroma.ts`.
